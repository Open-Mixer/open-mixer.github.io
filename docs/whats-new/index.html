02

On the console

The console's changes since openmixer 0.2.0, the last published release, one paragraph per group, each with the pages of the console's documentation that explain it.

Plugin hosting: one host for CLAP and LV2, three more omx effects, measured costs

Every plugin insert now runs in one host, CLAP directly and LV2 through its adapter (mod-host is retired), and the omx ducker, doubler and tone join the effects you can add from the picker.

Pages: /docs/manual/plugins, /docs/admin/ports, /docs/admin, /docs/architecture/technical-manual

Presets: a desk-wide preset library

Presets now live in a desk-wide library outside every session, saved in each plugin's own format, so LV2 presets you save are standard bundles other LV2 hosts can open.

Curves, meters and panels drawn from the shared libraries

EQ, gate and compressor curves, meter ballistics, units and plugin panels now come from the shared omx-dsp, omx-panel and omx-contract libraries, so the console, Zynthian and any other host draw them identically.

Pages: /docs/architecture/libraries, /docs/architecture/engine-and-libraries, /docs/manual/eq-dynamics, /docs/manual/metering-latency

Languages and coded messages

Languages arrive as installable packs read at run time, and every refusal, warning and fault reaches the surface as a code worded in your language, never as English text.

Pages: /docs/manual/look#language, /docs/rest/refusal-codes

Web surface: menus and editing fixes

On a narrow screen the header's menus fold into one MENU cap that opens each menu as its own submenu, quickly, and FX tiles open on the first tap.

Pages: /docs/manual/menus#on-a-narrow-screen-the-menu-cap, /docs/manual/plugins

Control

A Digidesign Control

Pages: /docs/control24

Audio graph and clock robustness

A desktop sound-settings profile switch can no longer take the clock-master interface out of its pro-audio profile at boot, and the console asks for it back while running.

Streams and the REST API

A stream subscriber can ask for lossless deltas (deltas=1) instead of whole bodies on large rows such as the edit history, and every row now declares its wire shape.

Pages: /docs/architecture/overview, /docs/rest

Assistant (MCP server)

The MCP server answers project questions from its corpus, starts cold within 10 s, and its HTTP entry binds loopback with an optional bearer token.

Pages: /docs/mcp

Packaging, releases and the Open-Mixer name

The project now publishes as OpenMixer from the Open-Mixer organisation, with packages built and install-tested on Fedora 44 and 45 and every library dependency held between a floor and a ceiling.

Pages: /docs/install, /docs/install/packages

RTA on Zynthian (design only)

The design for an analyser on Zynthian, drawn by the same renderer as the console, is settled; the analyser bands moving into omx-dsp are still in review.

Pages: /docs/manual/rta

How a change reaches the console: settle, verify and deploy gates

Every change now reaches the console through checked lanes and signed settles: a scan for private references in every message, library pins at the served version, a verification reused only for the exact same tree, temporary files cleaned up, and a deploy that checks what it installs.
